Each project gets a write-up page like this one, in `content/projects/`.

The site is built with Next.js and exported to static HTML for GitHub Pages.
Math is rendered at build time by KaTeX, e.g. the complexity of naive Fibonacci is
$O(\varphi^n)$ where $\varphi = \tfrac{1+\sqrt5}{2}$.
